# Causal Effect Discovery

This folder contains simulation scripts for evaluating **causal effect estimation**
performance under different network structures using Mendelian Randomization
methods, including **MR.RGM** and benchmark MR approaches.

The simulations focus on estimating **pairwise causal effects** between response
variables (traits), rather than recovering the full causal graph structure.

---

## Folder contents

This directory contains **four R scripts**, corresponding to three simulation
scenarios and one plotting/summary script:

### 1. `ScaleFree_CausalEffect_Parallel.R`

- Simulates data under a **scale-free causal network** among response variables.
- Generates individual-level genotype and phenotype data.
- Applies multiple MR methods (e.g., MR.RGM, IVW, median-based methods, Bayesian MR).
- Computes causal effect estimates and performance metrics across replicates.
- Designed to be run for different:
  - network sizes (e.g., p = 5, 10)
  - sample sizes (e.g., n = 500, 1000, 10000, 30000)

---

### 2. `SmallWorld_CausalEffect_Parallel.R`

- Simulates data under a **small-world causal network** structure.
- No horizontal pleiotropy beyond what is induced by the network.
- Uses the same evaluation framework as the scale-free case.
- Outputs causal effect estimation results across simulation replicates.

---

### 3. `SmallWorld_CausalEffect_Pleiotropy_Parallel.R`

- Simulates **small-world networks with horizontal pleiotropy**.
- Includes additional direct effects of instruments beyond their primary exposure.
- Evaluates robustness of causal effect estimation methods under pleiotropic violations.
- Includes MR.RGM variants and selected benchmark MR methods.

---

### 4. `CausalEffect_Performance_Plot.R`

- Aggregates results produced by the simulation scripts above.
- Generates comparative plots (e.g., boxplots) of causal effect performance metrics.
- Designed to work with saved result objects generated by the simulation scripts.
- Users should run the simulation scripts first before executing this file.

---

## How to use

1. Choose a simulation scenario:
   - Scale-free
   - Small-world
   - Small-world with horizontal pleiotropy

2. Run the corresponding `*_Parallel.R` script:
   - Adjust sample size and network size inside the script as needed.
   - Simulation outputs should be saved to disk (recommended).

3. Run `CausalEffect_Performance_Plot.R` to:
   - Load saved results
   - Generate summary figures for comparison across methods.

---

## Notes

- These scripts are **for reproducibility purposes only** and are **not part of the CRAN package**.
- Required external packages should be installed separately before running.
- All file paths should be adapted to local directory structures using relative paths where possible.
